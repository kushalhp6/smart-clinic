# Smart Clinic Management System - User Stories

## Admin User Stories

### US-001: Admin Login
**Role:** Admin

**User Story:**  
As an Admin, I want to log in securely so that I can manage the Smart Clinic Management System.

**Acceptance Criteria**
- Login requires a valid email and password.
- Invalid credentials display an error message.
- Successful login redirects to the Admin Dashboard.

**Priority:** High

**Story Points:** 3

---

### US-002: Manage Doctors

**Role:** Admin

**User Story:**  
As an Admin, I want to add, update, and remove doctor records so that the doctor information remains accurate.

**Acceptance Criteria**
- Admin can create a new doctor profile.
- Admin can edit doctor information.
- Admin can delete inactive doctor accounts.
- All changes are stored in the database.

**Priority:** High

**Story Points:** 5

---

### US-003: Manage Patients

**Role:** Admin

**User Story:**  
As an Admin, I want to manage patient records so that patient information remains accurate and up to date.

**Acceptance Criteria**
- Admin can view patient details.
- Admin can update patient information.
- Patient records are searchable.

**Priority:** High

**Story Points:** 5

---

### US-004: View Reports

**Role:** Admin

**User Story:**  
As an Admin, I want to generate appointment reports so that I can monitor clinic performance.

**Acceptance Criteria**
- Reports can be generated by date.
- Reports display total appointments.
- Reports identify doctors with the highest patient count.

**Priority:** Medium

**Story Points:** 5

---

# Doctor User Stories

### US-005: Doctor Login

**Role:** Doctor

**User Story:**  
As a Doctor, I want to log in securely so that I can manage my appointments.

**Acceptance Criteria**
- Doctor logs in using email and password.
- Invalid login attempts are rejected.
- Successful login opens the Doctor Dashboard.

**Priority:** High

**Story Points:** 3

---

### US-006: View Appointments

**Role:** Doctor

**User Story:**  
As a Doctor, I want to view all my appointments so that I know which patients I need to see.

**Acceptance Criteria**
- Displays appointments by date.
- Shows patient details.
- Shows appointment status.

**Priority:** High

**Story Points:** 5

---

### US-007: Update Availability

**Role:** Doctor

**User Story:**  
As a Doctor, I want to update my available time slots so that patients can book appointments only during my working hours.

**Acceptance Criteria**
- Doctor can add time slots.
- Doctor can remove unavailable slots.
- Updated availability is immediately visible.

**Priority:** Medium

**Story Points:** 5

---

### US-008: Create Prescription

**Role:** Doctor

**User Story:**  
As a Doctor, I want to create prescriptions after appointments so that patients receive proper treatment instructions.

**Acceptance Criteria**
- Prescription includes medicines and dosage.
- Prescription is linked to the appointment.
- Patient can view the prescription.

**Priority:** High

**Story Points:** 8

---

# Patient User Stories

### US-009: Patient Registration

**Role:** Patient

**User Story:**  
As a Patient, I want to register for an account so that I can access clinic services online.

**Acceptance Criteria**
- Registration requires valid information.
- Duplicate email addresses are not allowed.
- Successful registration creates a patient account.

**Priority:** High

**Story Points:** 5

---

### US-010: Search Doctors

**Role:** Patient

**User Story:**  
As a Patient, I want to search for doctors by name or speciality so that I can find a suitable doctor.

**Acceptance Criteria**
- Search supports doctor name.
- Search supports speciality.
- Matching doctors are displayed.

**Priority:** High

**Story Points:** 5

---

### US-011: Book Appointment

**Role:** Patient

**User Story:**  
As a Patient, I want to book an appointment with an available doctor so that I can receive medical consultation.

**Acceptance Criteria**
- Only available time slots are displayed.
- Booking confirmation is shown.
- Appointment is saved in the database.

**Priority:** High

**Story Points:** 8

---

### US-012: View Prescriptions

**Role:** Patient

**User Story:**  
As a Patient, I want to view my prescriptions so that I can follow my treatment plan.

**Acceptance Criteria**
- Displays all prescriptions.
- Shows medicines and doctor's notes.
- Prescriptions are ordered by date.

**Priority:** Medium

**Story Points:** 3
