# Smart Clinic Management System - User Stories

## Admin

- As an Admin, I want to log in securely so that I can manage the clinic.
- As an Admin, I want to add, edit, and remove doctors.
- As an Admin, I want to manage patient records.
- As an Admin, I want to view appointments and system reports.

## Doctor

- As a Doctor, I want to log in securely.
- As a Doctor, I want to view my daily appointments.
- As a Doctor, I want to update my available time slots.
- As a Doctor, I want to create prescriptions for patients.
- As a Doctor, I want to view a patient's medical history.

## Patient

- As a Patient, I want to register and log in.
- As a Patient, I want to search doctors by specialty or name.
- As a Patient, I want to book appointments.
- As a Patient, I want to view my appointments.
- As a Patient, I want to view my prescriptions.
